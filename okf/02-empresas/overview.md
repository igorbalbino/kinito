# Empresas

Tenant operacional. Possui motoristas, clientes, corridas, settings, subscription, referral.

## Campos-chave

`owner_user_id` · `cnpj` · `commission_rate` · `referral_code` · flags `is_distributor` `is_provider` `is_partner_enabled`

## API

`GET/PATCH /empresas/{id}` · `PUT .../settings` · partnerships · subscribe · WhatsApp · referral embutido em subscription

## Tela

`/empresas` · Config hub: Plano, Modelo, WhatsApp, Financeiro
